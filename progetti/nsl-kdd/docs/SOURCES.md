# Fonti e riferimenti organizzativi

- [Divekar et al., benchmark di riferimento](https://ieeexplore.ieee.org/document/8586840): protocollo e risultati, non codice degli autori.
- [NSL-KDD, UNB](https://www.unb.ca/cic/datasets/nsl.html): descrizione e significato dei file.
- [Jupyter in VS Code, Microsoft](https://code.visualstudio.com/docs/datascience/jupyter-notebooks): supporto per notebook, celle Markdown e scelta del kernel.
- [Cookiecutter Data Science, DrivenData](https://github.com/drivendataorg/cookiecutter-data-science): riferimento organizzativo per notebook e codice riutilizzabile. La nostra struttura è ridotta.
- [r7sy/IntrusionDetection](https://github.com/r7sy/IntrusionDetection): esempio narrativo di notebook NSL-KDD; usa un autoencoder e API datate, quindi non è l'implementazione del benchmark da replicare.

Consultazione: 1 novembre 2026. I repository citati sono riferimenti, non dipendenze adottate né garanzie di qualità dei risultati.
